# Noraiz Rana | MERN Stack Developer

A modern, high-performance developer portfolio built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. The portfolio showcases my projects, technical skills, experience, and provides a fully functional contact form powered by **Vercel Serverless Functions** and **Nodemailer**.

## 🌐 Live Demo

**Portfolio:** https://dev-portfolio-zeta-lime.vercel.app

---

## ✨ Features

- Modern dark-themed UI
- Fully responsive design
- Smooth page transitions & animations
- Interactive project showcase
- Skills, Experience & Education sections
- Downloadable Resume
- Contact form with validation
- Serverless backend using Vercel Functions
- Email notifications via Nodemailer
- Automatic reply email to visitors
- Optimized production build
- Fast loading with code splitting

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/NoraizRana/dev-portfolio.git
```

```bash
cd dev-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env.local` file in the project root.

```env
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_gmail_app_password
EMAIL_TO=your_email@gmail.com
```

> **Note:** Never commit your `.env.local` file.
